# EXPLOR’ACTION V4 — GITHUB FINAL

Application PWA FAFATRAINING conçue pour GitHub Pages uniquement.

## Installation GitHub Pages
1. Supprimer les anciens fichiers de la racine du dépôt (ne pas conserver les anciennes versions `app.js`, `data.js`, `style.css` ou `sw.js`).
2. Envoyer **tout le contenu de ce dossier** à la racine du dépôt.
3. GitHub > Settings > Pages > Deploy from a branch > `main` > `/(root)`.
4. Attendre le déploiement puis faire une recharge forcée du navigateur une fois.
5. Sur smartphone, supprimer l’ancien raccourci PWA s’il existe puis réinstaller Explor’Action V4.

## Limitation volontaire liée à « GitHub uniquement »
GitHub Pages est statique : il n’existe pas de serveur pour révoquer instantanément un code, synchroniser un classement mondial ou gérer des comptes. La V4 n’affiche donc aucun faux classement en ligne et reste autonome.
