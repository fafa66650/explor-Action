# Validation terrain obligatoire

Ce document est la checklist avant qu’une mission passe de « structurée » à « publiable ».

## 1. Itinéraire réel
- Suivre le parcours complet à pied dans le sens joueur.
- Enregistrer une trace GPX réelle.
- Mesurer distance totale, D+, D-, altitude min/max et durée de marche.
- Identifier le type de surface, passages raides, escaliers, pierres, route, traversées et exposition.
- Vérifier qu’aucune liaison ne suppose un passage privé/interdit ou une ligne droite impossible.

## 2. Points GPS
Pour chaque étape :
- relever plusieurs positions sur place ;
- choisir une zone sûre où le joueur peut s’arrêter ;
- mesurer la précision typique sous ciel dégagé et dans les ruelles/boisements ;
- ajuster le rayon de géofencing ;
- confirmer l’ordre géographique ;
- tester le déclenchement sur au moins deux téléphones différents.

## 3. Énigmes
- la réponse doit être observable ou déductible sur place ;
- aucune réponse ne doit être donnée par le titre de l’étape ;
- tester les variantes Enfant / Ado / Adulte ;
- diversifier observation, logique, orientation, association, code, ordre, détails patrimoniaux et défis légers ;
- éviter tout défi demandant de courir, grimper ou traverser une zone dangereuse.

## 4. Cotation physique
Attribuer Facile / Intermédiaire / Difficile en regardant l’ensemble : distance, dénivelé, effort, technicité et risque. Ne jamais classer uniquement par kilomètres.

## 5. Sécurité et saisonnalité
- météo, chaleur, tramontane ;
- risque incendie et restrictions d’accès aux massifs ;
- eau, ombre, réseau mobile ;
- horaires/fermetures ;
- chasse ou travaux si pertinents ;
- passages littoraux, falaises, routes, crêtes ;
- accessibilité PMR/poussette/partielle clairement annoncée.

## 6. Publication
Le statut « validé terrain » n’est accordé qu’après test complet du début au final, avec correction des coordonnées, du temps de jeu et des textes.
